# PomoRefresh

気分に合わせて集中時間を選び、時間帯に合ったリフレッシュを提案するポモドーロタイマーです。

操作方法は、[PomoRefresh ユーザーガイド](docs/user-guide.md)を参照してください。

## 起動方法

依存関係はありません。プロジェクトのルートで次のどちらかを実行し、ブラウザで `http://127.0.0.1:8000` を開いてください。

```bash
python -m http.server 8000
```

または、uvを利用している場合:

```bash
uv run pomorefresh
```

## 主な機能

- 3分・15分・25分・50分・90分の5つの集中モード
- 一時停止、リセット、途中で休める「ちょっと疲れた」操作
- ローカル時刻に合わせた各10種類のリフレッシュ提案
- 休憩終了時の効果音と完了演出
- 前回選択モードと当日の集中・ひと休み回数をブラウザに保存
- 直近の集中傾向を分析し、無理なく続けられる短いモードを提案
- MP3で再生する3種類の集中音、3分専用BGM、休憩用BGM
- 集中状態に応じたサウンドの自動切替、音量調整、ミュート
- Web Audio APIで生成するリフレッシュ完了チャイム
- 集中と休憩で育つ、5段階の植物育成・水やり機能

集中時間を提案する判定方法とデータ形式は、[集中時間提案ロジック説明書](docs/focus-time-recommendation.md)を参照してください。

植物の成長条件とゲームバランスは、[植物育成・水やり機能](docs/plant-system.md)を参照してください。

## テスト

集中時間の提案ロジックは、Node.js標準のテストランナーで確認できます。

```bash
node --test
```
