# PomoRefresh

気分に合わせて集中時間を選び、時間帯に合ったリフレッシュを提案するポモドーロタイマーです。

## 起動方法

依存関係はありません。プロジェクトのルートで次のどちらかを実行し、ブラウザで `http://127.0.0.1:8000` を開いてください。

```bash
python -m http.server 8000
```

または、uvを利用している場合:

```bash
uv run pomorefresh
```

## 主な機能

- 15分・25分・50分・90分の4つの集中モード
- 一時停止、リセット、途中で休める「ちょっと疲れた」操作
- ローカル時刻に合わせた各10種類のリフレッシュ提案
- 休憩終了時の効果音と完了演出
- 前回選択モードと当日の集中・ひと休み回数をブラウザに保存
