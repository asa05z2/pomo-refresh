# PomoRefresh ユーザーガイド

## PomoRefreshとは

PomoRefreshは、その日の気分や集中力に合わせて時間を選べるポモドーロタイマーです。

集中が続かなかったときも、途中で休むことを失敗として扱いません。最近の集中傾向に合った時間を提案し、集中と休憩を繰り返すことで小さな植物が育ちます。

## 1. アプリを開く

ターミナルでプロジェクトのフォルダへ移動し、次のコマンドを実行します。

```bash
uv run pomorefresh
```

ブラウザで次のページを開きます。

[http://127.0.0.1:8000](http://127.0.0.1:8000)

アプリを終了するときは、起動したターミナルで `Ctrl+C` を押します。

## 2. 集中時間を選ぶ

「集中モードを選ぶ」から、今の気分や作業内容に合った時間を選びます。

| モード | 集中 | 休憩 | おすすめの使い方 |
| --- | ---: | ---: | --- |
| とりあえず3分 | 3分 | 1分 | 手をつけるハードルを下げたいとき |
| ショート | 15分 | 3分 | 疲れているとき、短く区切りたいとき |
| クラシック | 25分 | 5分 | 標準的なポモドーロとして使いたいとき |
| ロング | 50分 | 10分 | プログラミングや執筆へじっくり取り組むとき |
| ウルトラディアン | 90分 | 20分 | 深い集中が必要な作業をするとき |

最後に選んだモードはブラウザに保存され、次回も選択された状態で開きます。

## 3. 集中中の音を選ぶ

通常の集中モードでは、次の3種類から音を選べます。

- 集中BGM
- 鳥と川
- 雨音

「とりあえず3分」では、3分専用BGMが自動的に選ばれます。

スピーカーボタンでミュートを切り替え、スライダーで音量を変更できます。音量、ミュート、最後に選んだ集中音はブラウザに保存されます。

集中・休憩BGMは曲の終わりと次の再生を短く重ね、途切れが目立たないようにループします。

## 4. 集中を始める

「集中をはじめる」を押すと、カウントダウンと音楽が始まります。

- 「一時停止」を押すと、タイマーと音楽が一緒に止まります。
- もう一度押すと、残り時間から再開します。
- 「リセット」を押すと、選択したモードの最初の時間へ戻ります。

ブラウザを別のタブへ切り替えても、終了予定時刻を基準に残り時間を計算します。

## 5. 集中が続かないとき

集中中に「ちょっと疲れた」を押すと、その場で集中を終了して休憩へ移れます。

途中で休んだ場合も、「ひと休み」の記録と水やりポイントが1つ増えます。無理にタイマーが終わるまで続ける必要はありません。

残り時間が全体の10%以下の場合は、ほとんど最後まで集中できたものとして完了扱いになります。

| モード | 完了扱いになる残り時間 |
| --- | ---: |
| 3分 | 18秒以下 |
| 15分 | 1分30秒以下 |
| 25分 | 2分30秒以下 |
| 50分 | 5分以下 |
| 90分 | 9分以下 |

## 6. リフレッシュする

集中が終わると、自動的に休憩画面へ移動します。集中音は休憩用BGMへ切り替わり、現在の時間帯に合ったリフレッシュ行動が1つ表示されます。

- 「できた！」で提案を実行したことを記録できます。
- 「ほかの提案を見る」で別の行動を表示できます。
- 「休憩を終える」で予定より早く休憩を終了できます。

休憩した満1分ごとに、水やりポイントを1つ獲得します。例えば2分40秒休んだ場合は2ポイントです。

休憩が終わるとチャイムが鳴り、完了画面が表示されます。「次のタスクを選ぶ」でモード選択画面へ戻ります。

## 7. 自分に合った集中時間の提案

PomoRefreshは、同じモードで最近どのくらい集中できたかを端末内で確認します。

次の条件を満たすと、モード一覧の上に「あなたへのおすすめ」が表示されます。

- 同じモードの履歴が3回以上ある。
- 直近5回のうち、3回以上かつ60%以上で「ちょっと疲れた」を使っている。
- 現在より短いモードがある。

たとえば、25分モードで15〜20分ほどの途中休憩が続いた場合は、15分モードを提案します。カードのボタンを押すと、提案されたモードへ切り替えられます。提案を使わず、今のモードを続けても問題ありません。

提案は、3回目の休憩完了後に「次のタスクを選ぶ」を押し、モード選択画面へ戻ったときに表示されます。

## 8. 植物を育てる

モード選択画面には、現在育てている植物が表示されます。

### 成長ポイント

集中を完了すると、基本的に「集中1分＝1成長ポイント」を獲得します。土の潤いが40〜85%なら、獲得ポイントが1.2倍になります。

| 段階 | 必要な累計ポイント |
| --- | ---: |
| 種 | 0pt |
| 芽 | 3pt |
| 葉 | 15pt |
| つぼみ | 40pt |
| 開花 | 90pt |

集中すると、1分につき土の水分を0.6%消費します。

### 水やり

水やりポイントは、次の方法で獲得できます。

- 「ちょっと疲れた」を使う：1ポイント
- 休憩する：経過した満1分ごとに1ポイント

「水やり」を押すと1ポイントを消費し、土の水分を20%回復します。水分が100%のときは水やりできません。

長い間アプリを開かなかった場合は、1日につき水分が5%減ります。水分が0%になっても植物は消えず、成長段階も失われません。水やりをすればすぐに回復します。

## 9. 今日の記録

画面右上の「TODAY」には、当日の記録が表示されます。

- 集中：完了した集中セッション数
- ひと休み：完了前に「ちょっと疲れた」を使った回数

記録は端末の日付が変わると、新しい日の集計へ切り替わります。

## 10. 保存とプライバシー

ログインやアカウント登録は必要ありません。次の情報はブラウザのLocalStorageだけに保存されます。

- 最後に選んだモード
- 今日の集中・ひと休み回数
- 直近20件の集中履歴
- 音量、ミュート、集中音
- 植物の成長、水分、水やりポイント

これらの情報は外部サーバーへ送信されません。ブラウザのサイトデータを削除すると、保存した記録も消去されます。

## 11. 困ったとき

### `Address already in use` と表示される

すでにPomoRefreshが起動しています。まず [http://127.0.0.1:8000](http://127.0.0.1:8000) を開いて確認してください。

起動中のターミナルが見つかる場合は、そこで `Ctrl+C` を押してから、もう一度次を実行します。

```bash
uv run pomorefresh
```

### 変更した画面が表示されない

macOSでは `Command+Shift+R` を押し、ページを強制再読み込みしてください。

### 音が鳴らない

- 画面のミュートが解除されているか確認します。
- 音量スライダーを上げます。
- ブラウザや端末自体がミュートされていないか確認します。
- 一度「集中をはじめる」を押します。完了チャイムは、この操作でブラウザの音声再生が許可された後に利用できます。
