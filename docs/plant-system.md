# 植物育成・水やり機能

## 概要

集中と休憩を植物の成長へ結びつけるゲーム化機能です。状態はLocalStorageの `pomorefresh:plant` に保存され、サーバーへ送信されません。

## パラメータ

| 項目 | 内容 |
| --- | --- |
| `growthPt` | 集中で得る累計成長ポイント |
| `waterPt` | 水やりに使えるポイント |
| `moisture` | 土の潤い。0〜100 |
| `plantStage` | 種、芽、葉、つぼみ、開花の5段階 |
| `updatedAt` | 最後に状態を更新した日時 |

## 成長

集中を完了すると、実際に完了扱いとなった分数と同じ成長ポイントを獲得します。水分が40〜85の適正範囲なら1.2倍です。集中1分につき水分を0.6消費します。

| 段階 | 必要な累計ポイント |
| --- | ---: |
| 種 | 0 |
| 芽 | 3 |
| 葉 | 15 |
| つぼみ | 40 |
| 開花 | 90 |

## 水やり

- 「疲れた」を押すと水やりポイントを1獲得します。
- 休憩終了時、実際に経過した満1分ごとに1ポイントを獲得します。
- 水やり1回でポイントを1消費し、水分を20回復します。
- 水分100では水やりできません。

## 長期不在

水分は不在1日につき5低下し、最低0で止まります。水分がなくなっても植物、成長ポイント、成長段階は失われません。水やりをすればすぐに回復します。

## テスト

```bash
node --test
```

`tests/plant-manager.test.js` で初期状態、成長ボーナス、段階、水やり、長期不在を検証しています。
